SHOP.CO — WordPress / WooCommerce Assignment

A responsive e-commerce website implementation based on the SHOP.CO design, developed using WordPress, WooCommerce, Elementor, Astra, and a custom Astra Child Theme.

Features
Responsive desktop, tablet, and mobile layouts
Custom Astra Child Theme
WooCommerce product/shop functionality
Custom product ratings and review display
Product discount badges
Responsive header and navigation
Search functionality with mobile toggle
Cart and My Account icons
Custom fonts
Elementor-based page sections
Mobile-friendly UI interactions
Custom PHP, CSS, and JavaScript functionality

Local Setup
Install WordPress using MAMP.
Create a MySQL database.
Import:
database/shopco.sql
Copy the project wp-content directory into the WordPress installation.
Install/activate the required plugins.
Activate the Astra Child Theme.
Update the WordPress site URL if required for the local environment.
Open the website in your local WordPress installation.
Database

A database export is included in:

database/shopco.sql

The original local database name was:

wp_shop

Important

The project uses a local MAMP environment, so the original local URL is not included as a live/demo URL. The database/site URL may need to be updated when setting up the project on another environment.
